# Week 3 – Infrastructure as Code, Containerization & CI/CD

Week 3 shifts from manual console-driven AWS work to automated, code-based infrastructure and deployment: Terraform for provisioning, Docker for packaging the application, GitHub Actions for CI/CD, and CloudWatch for monitoring.

## Summary
By the end of Week 3, infrastructure was defined and provisioned entirely in code (Terraform, with a modular structure and remote S3 backend), the application was containerized with Docker, builds were automated via GitHub Actions, and the deployed environment was monitored with CloudWatch — culminating in a published GitHub repository documenting the full pipeline.

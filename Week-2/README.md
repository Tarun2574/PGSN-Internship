By the end of Week 2, a static website was live on an EC2 instance behind a custom VPC (public/private subnets, Internet Gateway, NAT Gateway, route tables, security groups), and both S3 (static hosting) and EBS (attached volume with snapshot) storage patterns had been explored and verified. The Week 2 architecture is documented in Task 2.4.

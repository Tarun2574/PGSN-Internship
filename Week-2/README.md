# Week 2 – AWS Compute & Networking

## Overview

This week focused on building AWS infrastructure manually to understand core cloud networking and compute concepts before moving to Infrastructure as Code.

## Learning Objectives

* Launch and manage EC2 instances
* Configure secure SSH access
* Design a custom VPC
* Configure public and private subnets
* Work with Internet Gateway and NAT Gateway
* Explore S3 and EBS storage
* Create an AWS architecture diagram

## Tasks Completed

### Task 2.1 – Web Server on EC2

* Launched an EC2 instance
* Connected securely using SSH
* Installed Nginx
* Hosted a simple static web page
* Associated an Elastic IP for public access

### Task 2.2 – Custom VPC

* Created a custom VPC
* Configured one public and one private subnet
* Attached an Internet Gateway
* Configured a NAT Gateway
* Created and associated route tables

### Task 2.3 – Storage

* Hosted a static website using Amazon S3
* Created and attached an EBS volume
* Created an EBS snapshot and restored a volume from it

### Task 2.4 – Architecture

* Designed an AWS architecture diagram illustrating the networking components and traffic flow.

## AWS Services Used

* Amazon EC2
* Amazon VPC
* Amazon S3
* Amazon EBS
* Internet Gateway
* NAT Gateway
* Route Tables
* Security Groups
* Elastic IP
